급식 게시자료 프롬프트 생성기

학교 검색 → 조회 범위 설정 → 급식 불러오기(조식·중식·석식) → 식단 다듬기 순서로 원하는 디자인 프리셋의 AI 이미지 생성 프롬프트를 만듭니다.

🧩 기간 설정 + 디자인 프리셋
• 학교 검색 → 조회 범위 설정 → 급식 불러오기 → 식단 다듬기 순서로 작업하세요.
🏫 1. 학교 검색
나이스 개방포털 API를 통해 학교와 급식을 조회합니다.
유치원 선생님 전용 또는 학교 검색이 안 되는 학교의 경우, 나이스에서 월간식단표를 엑셀로 다운받아 업로드해 주세요. 학교 검색 없이 조회 범위에 맞는 식단이 자동으로 입력됩니다.
📅 2. 조회 범위 설정
현재 자료 구성: 하루 게시자료
🍱 3. 선택 기간 급식 불러오기
💾 내 저장 식단 (불러온 식단은 자동 저장돼요)
펼치면 저장된 식단이 나와요.
